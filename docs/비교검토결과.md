# JetBrains AI Assistant와 Cline 비교 검토

작성일: 2026-11-05

## 결과
같은 Qwen 모델과 같은 로컬 MCP로 샘플 파일 읽기 → 수정 → 다시 읽기를 수행했고, 두 도구 모두 성공했다. 간단한 파일 작업에서 기능을 사용할 수 있음을 확인한 결과이며, 실제 프로젝트 전체 작업의 동등성이나 효율성을 입증한 것은 아니다.

사용자가 전달한 실행 결과를 바탕으로 정리했으며, 작성 시 실제 hello.txt와 양쪽 도구 호출 로그를 읽어 확인했다. 테스트를 이 문서 작성 과정에서 새로 실행하거나 파일 내용을 수정하지 않았다.

## 공통 조건
- 모델: Qwen/Qwen3.8-27B-FP8
- OpenAI 호환 주소: https://YOUR-MODEL-SERVER/v1
- MCP: @modelcontextprotocol/server-filesystem / local-sample-files
- 접근 범위: outputs/jetbrains-ai-review/sample-project만 허용
- 파일: hello.txt
- 변경 순서: verified → jetbrains-tested → cline-tested

## 비교
| 항목 | JetBrains AI Assistant | Cline CLI |
|---|---|---|
| 실제 파일 읽기·수정·재확인 | 성공 | 성공 |
| MCP 호출 | 허용 폴더 확인 → 읽기 → 수정 → 재읽기 | 허용 폴더 확인 → 파일 검색 → 읽기 → 수정 → 재읽기 |
| 오류 처리 | 첫 수정 요청의 인자 형식이 잘못됐으나 재시도 성공 | 전달 결과 및 확인한 도구 기록에서 해당 오류 없음 |
| 화면 | 사용자 확인: IntelliJ AI Chat에서 내용과 diff 표시 | 사용자 확인: 터미널에서 실행 결과 표시 |
| 승인 | 사용자 확인: 이번 실행에서 승인창 없음 | 사용자 확인: 자동 승인 꺼짐, 단계별 승인 가능 |
| 소요 시간 | MCP 첫 호출부터 최종 읽기 요청까지 약 11초 | 사용자 측정 약 1분; 로그상 첫 MCP 도구 사용 기록부터 마지막까지 약 33초 |
| 설정 | 공급자 URL, 모델 배정, MCP 및 무료 라이선스 활성화 | 실행 스크립트, 모델 연결 설정 및 MCP JSON |

시간은 측정 구간이 다르고 승인 대기, 파일 검색, 모델 생성 시간이 영향을 주므로 성능 우열을 판단하는 수치로 사용하지 않는다. Cline이 검색을 먼저 했다는 사실만으로 더 안전하다고 단정하지 않는다. Cline의 $0 표시는 RunPod 인프라 비용이 없다는 뜻이 아니다.

## 설정 중 해결한 문제
JetBrains AI에서 'No compatible model is available for Chat mode'가 발생했다. Providers & API keys의 Model Assignment에서 Core features와 Instant helpers를 OpenAIAPI/Qwen/Qwen3.8-27B-FP8로 지정한 후 사용자가 성공을 확인했다.

기존 AI Assistant는 오른쪽 AI Chat 아이콘(Alt+Shift+1)으로 열었다. Air의 New Session 화면과 구분해야 한다. air-switch.xml을 추가 수정할 필요는 없다.

## 검토 의견과 한계
IntelliJ 안에서 채팅과 변경 내용을 보며 간단한 파일 작업을 하려면 JetBrains AI Assistant를 사용할 수 있다. 터미널 작업을 선호하면 Cline CLI도 같은 모델과 MCP로 작업할 수 있다. 이번 검증만으로 어느 쪽이 전반적으로 더 효율적인지 판단할 수는 없다.

샘플 파일 하나로 각각 한 번 실행했다. 여러 파일 수정, 빌드·테스트, 실제 프로젝트 작업, 각 클라이언트의 승인 정책 및 폴더 밖 접근 거부는 이번 비교에서 추가 검증하지 않았다. 'JetBrains AI activation is incomplete' 안내는 사용자에 따르면 남아 있지만 이번 채팅 사용에는 지장이 없었다.

테스트 파일은 cline-tested 상태로 유지했다. 모델 주소, 접근 범위, 프로그램 설치 상태 및 계정정보는 변경하지 않았다.
