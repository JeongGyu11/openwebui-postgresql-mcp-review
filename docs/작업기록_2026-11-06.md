# 2026-11-06 작업 기록

## PostgreSQL 자료를 CSV와 표로 제공
기존 줄 단위 TXT 대신 CSV를 생성하고 UTF-8 BOM을 적용했다. 컬렉션 파일 미리보기는 CSV를 파싱해 표로 표시한다. 기존 테이블을 다시 가져오면 같은 문서를 갱신한다. 숫자·한글·JSON·불리언과 따옴표/개행 처리를 확인했다.

## 채팅 첨부 시 DB 최신화
백그라운드 주기 동기화 대신 DB 파일 또는 컬렉션을 선택하는 시점에 최신 데이터를 재조회한다. 갱신이 끝나기 전에는 첨부/전송하지 않는다. 연결 실패 시 오래된 자료를 최신 자료인 것처럼 첨부하지 않고 오류를 표시한다. 동일 데이터는 다시 쓰지 않는다.

`knowledge_database.py`의 refresh-attachment API, `InputMenu.svelte`의 선택 처리, `MessageInput.svelte`의 대기·전송 제한을 함께 수정했다. 파일/컬렉션 권한을 확인하며 접속정보는 서버에 암호화해 보관한다. 기존 문서에 접속정보가 저장되어 있지 않으면 DB 연동 화면에서 다시 가져와야 한다. WEBUI_SECRET_KEY 변경 시 기존 연결정보 복호화가 불가능할 수 있다.

## 모델 및 코딩 도구 검토
RunPod의 OpenAI 호환 엔드포인트로 모델 연결을 갱신했다. Qwen/Qwen3.8-27B를 이용한 Cline의 Filesystem MCP 파일 읽기→수정→재확인을 재검증했다. 과거 동일 FP8 모델을 사용한 JetBrains AI/Cline 비교 결과와 이번 재검증은 구분해서 보관한다. 이 기록으로 도구 전체 성능의 우열을 단정하지 않는다.

JetBrains AI로 Open WebUI의 초기 테마 코드를 수정했다. `src/app.html`과 General 설정 컴포넌트에서 미설정 기본값을 dark로 변경했으며 기존 사용자 선택은 유지한다. 소스 변경은 확인했으나 모든 브라우저·운영체제 조합의 시각 검증을 수행한 것은 아니다.

## 사내 네트워크 접속
개발 프런트엔드의 LAN 바인딩, 백엔드 허용 origin과 Windows 방화벽 설정으로 같은 서브넷 접근을 구성했다. 개인 IP, 실제 서버 주소와 계정정보를 저장소에 넣지 않았다. 재현 시 자신의 환경에 맞게 origin·방화벽을 설정해야 한다. 개발 서버를 인터넷 공개 운영 서버로 간주하지 않는다.

## DDL·소스 기반 영향도 분석
OBiX 샘플 프로젝트와 DDL을 읽어 테이블 29개/FK 19개, 서비스·DAO·SQL·화면 연결 관계를 정적으로 조사했다. 분석 자료는 `docs/impact-analysis/`에 있다.

| 유형 | 시나리오 |
|---|---|
| 테이블 간 | 사용자 ID 길이 확대 / 게시글 번호 자료형 변경 |
| 테이블과 소스·화면 | 사용자명 컬럼 변경 / 배치 기본 테이블 삭제 |
| 소스 내·소스 간 | 사용자 권한 저장 기능 제거 / 배치 목록 메서드 변경 |

총 6개이며 각 시나리오는 질문·후속 질문·추가 확인의 3턴과 예상 답변으로 구성했다. 직접 참조와 간접 영향, 필수 수정과 점검 후보를 구분했다. 실제 ALTER·테이블 삭제·샘플 코드 수정은 수행하지 않았다. 동적 호출·외부 의존성과 실행 중 분기는 추가 검증이 필요하다.

## Open WebUI 지식기반 등록 상태
등록명은 'OBiX 샘플 코드 · DDL 영향도 분석'이다. 원본 경로를 표시한 코드 578개를 모듈별로 묶어 DDL·파일 목록 포함 문서 18개로 저장했다. AI가 작성한 예상 답변은 평가 자료 오염을 피하려고 지식기반에 넣지 않았다.

**자료 저장/연결만 완료했다.** 현재 Slim 실행 환경의 pgvector 저장소 주소가 설정되지 않아 일반 등록 API의 색인이 실패했다. 이후 기존 앱의 파일·지식기반 모델 함수를 사용해 텍스트와 연결 정보를 저장하고 목록 18개를 API로 재확인했다. 벡터 색인이 완료된 것처럼 보고하지 않는다. 자동 검색 및 시나리오 답변 검증을 진행하려면 검색 저장소와 임베딩 설정 후 재색인이 필요하다.

## 검증 및 제외 자료
- CSV 다운로드·같은 ID 갱신 확인 기록, 첨부 시 최신화/권한/실패 처리 10항목 기록을 `docs/verification/`에 보관했다. CSV 기록의 행 수는 당시 검증 시점의 3행이며 현재 로컬 샘플 행 수를 뜻하지 않는다.
- 로컬 샘플 테이블은 이후 행을 추가해 각각 7행이 되었다. 기존 `database/sample-data.sql`은 초기 재현용 3행 예제를 유지한다.
- 이번 export에서는 Python 구문 확인과 git diff 검사를 수행한다. 전체 Open WebUI 빌드·회귀 테스트를 새로 수행한 것은 아니다.
- 계정정보, 비밀키, 암호화 연결 저장 파일, 실제 DB·로그·캐시·설치 도구, 사내 Cline 소스는 제외한다. 샘플 참고 자료는 비공개 검토용으로 유지한다.
